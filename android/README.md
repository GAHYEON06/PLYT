# PLYT Android

WebView 없이 Kotlin과 Android 네이티브 View로 만든 앱입니다. 고객과 사장님이 같은 C++ API 서버를 사용합니다.

## 프로젝트 열기

Android Studio에서 이 `android` 폴더를 엽니다. 로컬 개발 SDK는 `C:\AndroidStudioSDK`로 설정했습니다. 다른 컴퓨터에서는 `local.properties`의 SDK 경로를 변경하세요.

- Android Gradle Plugin: 9.3.3
- Gradle Wrapper: 9.5.0
- compile/target SDK: 37
- 최소 지원: Android 8.0 (API 26)
- applicationId: `com.plyt.app`
- 빌드: `gradlew.bat assembleDebug`

## 서버 연결

앱 하단 **설정 → 서비스 연결**에서 서버 주소를 변경합니다. 경로 없이 주소와 포트만 입력합니다. 서버를 변경하면 기존 토큰은 제거되어 해당 서버에서 다시 로그인해야 합니다.

- Android Emulator 기본값: `http://10.0.2.2:8080`
- USB 연결 기기: `adb reverse tcp:8080 tcp:8080` 후 앱 주소를 `http://127.0.0.1:8080`으로 설정
- 인터넷 배포: C++ API와 웹을 서비스하는 HTTPS 주소를 입력

개발 APK는 HTTP를 허용합니다. release 빌드는 HTTP를 차단하며 기본 서버 주소를 비워 둡니다. 로그인 토큰은 앱 전용 SharedPreferences에 저장하고 기기 백업은 비활성화했습니다. 비밀번호는 저장하지 않습니다.

## 기능

- 공간 조회, 검색, 유형 필터, 계정별 저장
- 회원가입, 로그인, 로그아웃, 사장님 최초 등록 코드
- 날짜 선택, 30분 단위 시작 시간, 1–4시간 이용, 추가 부담 한도
- 고객 요청, 기존 예약자의 이동 수락, 요청자의 조건 수락, 거절 및 확정 전 취소
- 사장님 예약 변경 제안, 원래 예약 시스템 반영 확인번호 기록
- 요청별 진행 기록 조회
- 서버 주소 설정, 서버 변경 시 세션 분리

회원가입 화면에 이름·이메일·암호화된 비밀번호 및 서비스 기록이 연결한 서버에 저장된다는 안내를 포함했습니다. 사장님 등록 코드는 서버 `data/owner-setup-key.txt` 파일에서 직접 확인합니다. 등록 코드를 앱이나 저장소에 하드코딩하지 않았습니다.

화면의 공간 이미지는 외부 사진 의존 없이 네이티브 Canvas로 그린 공간 일러스트입니다. 실제 업체 사진과 입점 정보는 추후 등록해야 합니다.

## 현재 제한

공간은 예시 데이터이며 외부 예약 시스템, 결제, 보상 지급, 문자 및 푸시 알림은 연결하지 않았습니다. 진행 화면의 **새로고침**으로 최신 데이터를 가져옵니다. 제안 수락을 실제 예약 확정이나 결제로 표시하지 않습니다.
