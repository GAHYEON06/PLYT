THE PLYT WAY

좋은 시간은, 함께 만들어요.

원하는 시간의 신규 고객과, 일정 변경이 가능한 기존 예약자를 업체가 연결해요.

  1. 희망 시간과 추가 부담 한도를 등록해요.
  2. 업체가 기존 예약자에게 대체 시간과 보상을 제안해요.
  3. 기존 예약자가 먼저 수락하고, 요청 고객도 동의해요.
  4. 업체가 원래 예약 시스템에서 변경한 뒤 확정 기록을 남겨요.
현재는 파일럿입니다. 예시 공간을 사용하며 실제 결제, 보상 지급, 외부 예약 자동 변경, 문자 알림은 제공되지 않아요. 확정 기록은 업체의 수동 확인을 뜻해요.
